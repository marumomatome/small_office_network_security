# Network Security Measures

## 1. Router Authentication

Administrator authentication is configured to prevent unauthorised access to router configuration.

## 2. SSH Remote Administration

SSH version 2 is configured for encrypted remote administration instead of Telnet.

## 3. Switch Port Security

Sticky MAC address learning and port security are configured to limit the number of devices permitted on selected switch ports.

## 4. Unused Port Shutdown

Unused switch interfaces are administratively disabled to reduce unauthorised physical network access.
